<h1>URL Shortener – Node.js Backend</h1>
<h2>Description</h2> 
<p>This is a simple URL Shortener backend built using Node.js and Express.  
It converts long URLs into short URLs and redirects the short URL back to the original URL</p>

<h2>Features</h2> 
1.Generate short URLs<br>
2.Redirect short URL to original URL<br>
3.REST API based backend<br>
4.No frontend <br>
